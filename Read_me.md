# E-Commerce Sales Analysis

An end-to-end data analytics project that transforms raw e-commerce sales data into meaningful business insights using Python. The project covers data cleaning, exploratory data analysis (EDA), sales KPIs, product performance, customer behavior, regional analysis, visualizations, and business recommendations.

**Stack:** Python · pandas · NumPy · Matplotlib · Seaborn · Jupyter Notebook

## How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd ecommerce_sales_analysis
```

### 2. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter nbformat nbclient ipykernel
```

### 3. Add the dataset

Place your CSV file in the `data/` directory and name it:

```text
ecommerce_sales.csv
```

If your dataset has a different name or location, update the path in `create_ecommerce_notebook.py`.

### 4. Build and execute the notebook

```bash
python create_ecommerce_notebook.py
```

The script creates and executes:

```text
notebooks/E-Commerce_Sales_Analysis.ipynb
```

The executed notebook contains the code, tables, charts, and outputs generated during analysis.

### 5. View the results

Open `notebooks/E-Commerce_Sales_Analysis.ipynb` in Jupyter Notebook or Visual Studio Code to explore the analysis.

## Methodology

### 1. Data Loading and Inspection

- Load the CSV dataset using pandas.
- Inspect the number of rows and columns.
- Review column names and data types.
- Identify missing values and duplicate records.
- Generate descriptive statistics.

### 2. Data Cleaning

- Standardize column names.
- Remove duplicate records where appropriate.
- Convert date columns to datetime format.
- Convert sales, price, quantity, and other numerical columns to appropriate data types.
- Identify missing and invalid values.
- Validate the cleaned dataset before analysis.

### 3. Key Performance Indicators (KPIs)

The analysis calculates relevant metrics based on the columns available in the dataset, such as:

- Total revenue
- Average sales value
- Median sales value
- Total quantity sold
- Number of unique customers
- Best-performing product and category
- Best-performing region

### 4. Exploratory Data Analysis (EDA)

**Sales distribution:** Understand the distribution of sales values and identify potential outliers.

**Category analysis:** Compare sales across product categories.

**Product analysis:** Identify the top-selling products based on revenue.

**Time-series analysis:** Explore monthly sales trends and possible seasonal patterns.

**Regional analysis:** Compare sales performance across regions, cities, or countries.

**Customer analysis:** Identify high-value customers when customer identifiers are available.

### 5. Data Visualization

Matplotlib and Seaborn are used to create visualizations, including:

| Visualization | Purpose |
|---|---|
| Sales distribution histogram | Understand sales value distribution |
| Bar chart by category | Compare category performance |
| Monthly sales line chart | Identify sales trends over time |
| Top-products bar chart | Highlight high-revenue products |
| Regional sales chart | Compare geographical performance |
| Correlation heatmap | Explore relationships between numerical variables |

### 6. Business Insights

The analysis uses the results from the dataset to identify:

- Products and categories that contribute most to revenue.
- Periods with high or low sales.
- Regional differences in sales performance.
- Customers with high purchase value, when customer data is available.
- Potential opportunities to improve revenue and sales performance.

Insights and recommendations should be based on the actual analysis results rather than assumed values.
